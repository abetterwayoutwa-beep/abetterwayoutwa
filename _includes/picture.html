{%- comment -%} Responsive for one image. Set these before including: pic the image ({ src, alt }, optional width/height) pic_sizes the "sizes" attribute (how wide it shows on screen) pic_attrs extra attributes, e.g. loading="lazy" or fetchpriority="high" Width, height, and the WebP srcset come from _data/images.json, which _tools/images.py writes in CI. Without it, the original image is used as is. {%- endcomment -%} {%- assign info = site.data.images[pic.src] -%} {%- assign pw = pic.width | default: info.width -%} {%- assign ph = pic.height | default: info.height -%}
